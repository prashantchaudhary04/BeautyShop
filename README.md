# Beauty Shop — E-Commerce Website

A modern beauty and cosmetics e-commerce website built using HTML,
CSS, and JavaScript. The project includes a customer-facing
shopping interface, account page, wishlist, order tracking,
checkout UI, and an admin dashboard.

It's only just a ui developed through html, css and javascript.

## Technologies Used:

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive Web Design

## Pages

### Home Page
- Hero section
- Product categories
- Promotional banners
- Product listings
- Deals
- New arrivals
- Testimonials
- Blog section
- FAQ
- Newsletter
- Shopping cart UI
- Wishlist UI

### Account Page
- Customer profile
- Wishlist
- Order tracking
- Checkout summary
- Delivery preferences

### Admin Dashboard
- Product management UI
- Category management UI
- Inventory management UI
- Order management UI
- Customer management UI
- Coupons and discounts
- Blog/CMS management
- Homepage/banner management
- Sales analytics
- Payment and shipping settings
